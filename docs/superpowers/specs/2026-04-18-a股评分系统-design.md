# A股评分系统 设计文档

**日期：** 2026-04-18  
**状态：** 已确认

---

## 1. 项目概述

开发一个本地运行的 A 股多维度评分系统，通过 pywencai（问财）采集数据，结合本地技术指标计算，对股票进行评分并通过 Web 界面展示排行榜、详情和历史趋势。

### 使用场景
- 每日批量扫描，输出评分排行榜（选股）
- 自选股跟踪监控
- 特定股票多维度深度分析
- 手动按需触发采集和评分

## 4. 评分维度与指标

### 4.1 技术面（本地 pandas-ta 计算）

| 指标 | 参数 |
|---|---|
| 移动均线 | MA5 / MA13 / MA30 |
| MACD | DIF / DEA / 柱状值 |
| RSI | 周期 14 |
| KDJ | 参数 9,3,3 |
| 布林带 | 上轨 / 中轨 / 下轨 |
| 量比 | 当日成交量 / 5日均量 |

### 4.2 资金面（pywencai 查询）

| 指标 | 说明 |
|---|---|
| 主力净流入（当日/5日） | 最核心资金指标 |
| 超大单净流入 | 机构动向 |
| 北向资金净买入 | 外资动向 |
| 融资净买入 | 杠杆资金方向 |

### 4.3 基本面（pywencai 查询）

| 指标 | 说明 |
|---|---|
| PE / PB | 估值 |
| ROE | 盈利质量 |
| 净利润增速（同比） | 业绩趋势 |
| 市值 | 规模分层 |

### 4.4 消息面（pywencai 查询）

| 指标 | 说明 |
|---|---|
| 研报数量/评级 | 机构关注度 |
| 公告类型 | 利好/利空判断 |
| 新闻情感 | 正负面倾向 |

### 4.5 市场热度（pywencai 查询）

| 指标 | 说明 |
|---|---|
| 涨跌幅 | 价格动量 |
| 换手率 | 活跃度 |
| 量比 | 放量信号 |
| 连板数 | 强势标志 |
| 所属板块热度排名 | 板块效应 |

## 5. 评分策略

三套预设策略，各维度权重如下：

| 策略 | 技术面 | 资金面 | 基本面 | 消息面 | 市场热度 |
|---|---|---|---|---|---|
| 短线策略 | 35% | 25% | 0% | 10% | 30% |
| 趋势策略 | 40% | 30% | 5% | 5% | 20% |
| 价值策略 | 20% | 15% | 50% | 10% | 5% |

每个维度满分 100 分，总分 = Σ（维度分 × 权重）。

## 6. 数据库设计

### stocks（股票基本信息）
```sql
code TEXT PRIMARY KEY,
name TEXT,
market TEXT,              -- SH / SZ
is_watchlist BOOLEAN,     -- 是否自选股
index_tags TEXT,          -- JSON 数组，如 ["hs300","zz500"]
created_at DATETIME,
updated_at DATETIME
```

### daily_data（每日原始采集数据）
```sql
code TEXT,
date TEXT,
-- 技术面
ma5 REAL, ma13 REAL, ma30 REAL,
macd_dif REAL, macd_dea REAL, macd_bar REAL,
rsi14 REAL,
kdj_k REAL, kdj_d REAL, kdj_j REAL,
boll_upper REAL, boll_mid REAL, boll_lower REAL,
volume_ratio REAL,
-- 资金面
main_inflow_today REAL, main_inflow_5d REAL,
super_large_inflow REAL,
north_inflow REAL,
margin_net_buy REAL,
-- 基本面
pe REAL, pb REAL, roe REAL,
profit_growth_yoy REAL,
market_cap REAL,
-- 消息面
report_count INTEGER, report_rating TEXT,
announcement_type TEXT,
news_sentiment REAL,
-- 市场热度
change_pct REAL,
turnover_rate REAL,
consecutive_limit_up INTEGER,
sector_heat_rank INTEGER,
PRIMARY KEY (code, date)
```

### scores（评分结果）
```sql
code TEXT,
date TEXT,
strategy TEXT,            -- short_term / trend / value
technical_score REAL,
capital_score REAL,
fundamental_score REAL,
news_score REAL,
heat_score REAL,
total_score REAL,
PRIMARY KEY (code, date, strategy)
```

### strategies（策略配置）
```sql
name TEXT PRIMARY KEY,
display_name TEXT,
technical_weight REAL,
capital_weight REAL,
fundamental_weight REAL,
news_weight REAL,
heat_weight REAL
```

## 8. API 设计

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/scores/leaderboard` | 排行榜（strategy, type=watchlist/other） |
| GET | `/api/scores/{code}` | 股票最新各维度评分详情 |
| GET | `/api/scores/{code}/history` | 历史评分趋势 |
| GET | `/api/stocks/watchlist` | 自选股列表 |
| POST | `/api/stocks/watchlist` | 添加自选股 |
| DELETE | `/api/stocks/watchlist/{code}` | 删除自选股 |
| POST | `/api/trigger/collect` | 手动触发全量采集+评分 |
| GET | `/api/trigger/status` | 采集任务状态 |

## 9. Web UI 设计

### Dashboard（评分排行榜）
- 顶部：策略选择器（短线/趋势/价值）+ 手动采集按钮 + 最后更新时间
- **自选股 Tab**：表格，列：排名/股票名/代码/总分/五维度小分/涨跌幅/详情链接
- **其他股票 Tab**：同结构，支持按任意维度排序，含来源标签（指数/热门板块）

### StockDetail（股票详情）
- 顶部：股票名、代码、涨跌幅、总分徽章
- 左侧：ECharts 雷达图（五维度评分）
- 右侧：五个维度评分卡片，显示分项指标值和得分
- 底部：原始指标数据表格

### History（历史趋势）
- 股票选择器 + 策略选择器 + 时间范围（7天/30天/全部）
- ECharts 折线图：总分 + 五维度分随日期变化

## 10. 关键设计决策

- **upsert 策略**：所有写入使用 `INSERT OR REPLACE`，相同 (code, date) 或 (code, date, strategy) 覆盖更新
- **评分标准化**：每个维度内部将原始指标映射到 0-100 分，便于跨维度比较
- **采集容错**：单只股票采集失败不中断整批，记录错误日志继续
- **热门板块查询**：通过 pywencai 查询当日板块涨幅排行，取 Top10 板块，每板块取涨幅前5只股票
